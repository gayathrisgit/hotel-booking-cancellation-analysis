
# Hotel Booking & Cancellation Analysis Using MySQL

## Project Overview
This project analyzes hotel booking data using MySQL to understand booking trends, room preferences, customer bookings, and cancellation patterns.

## Tools Used
- MySQL
- MySQL Workbench

## Database Tables
- Customers
- Rooms
- Bookings

## SQL Concepts Used
- CREATE DATABASE and CREATE TABLE
- INSERT and SELECT
- WHERE and ORDER BY
- COUNT and SUM
- GROUP BY
- INNER JOIN
- CASE statements
- DATEDIFF and DATE_FORMAT
- Cancellation Rate Analysis

## Key Analysis
1. Total booking count
2. Booking status analysis
3. Room-wise booking count
4. Estimated booking value by room type
5. Room-wise cancellation analysis
6. Customer booking details
7. Cancellation percentage
8. Average stay duration
9. Monthly booking analysis

## Project Purpose
This project helped me practice SQL queries and analyze hotel booking data to understand business trends.

`Hotel_Booking_Cancellation_Analysis.sql`
